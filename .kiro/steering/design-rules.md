# Design Rules — Portfolio

These are hard constraints for any work on this portfolio. The current design is
being fully reworked. Do not carry over or reintroduce the old visual style.

## Do NOT introduce

- modern SaaS cards
- large rounded components
- gradients
- excessive shadows
- glassmorphism
- generic portfolio sections
- giant hero text
- unnecessary animations

## Notes

- Keep the aesthetic restrained and intentional. Prefer sharp, minimal, deliberate
  layouts over decorative effects.
- When in doubt, leave it out. Add visual complexity only when the user explicitly
  asks for it.
